# Product steering — PHANTOM PACKET

Created 2026-11-20 for Kiroween 2026 **Resurrection**. Inspired by BBS/FidoNet packet-message workflows: carry a versioned bulletin board packet to another browser without an online server. Do not falsely advertise live networking, cryptographic authentication, or emergency alerts.

**Principles:** zero backend, deterministic offline-first, user-owned browser data, file-based manual exchange, safe read-only import validation, accessible responsive haunted-terminal style, original code developed with authenticated Kiro CLI. Fictional examples must be labeled as demos. A malformed packet must never execute HTML or JS.

**Out of scope:** real peer networking, real identity validation, actual emergency routing, CereX production or corporate data, external analytics, paid LLM model inference.

**Real build history:** Kiro CLI 3.5.0, AWS Builder ID, authenticated 2026-11-20. Kiro Write File and Replace in File created the starter modules, HTML, worker and 27 initial tests. The maintainer corrected integration issues and added security tests, to be explicitly disclosed to judges. No source from pre-existing CereX project was copied.
